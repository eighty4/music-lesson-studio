# Music Lesson Studio - UI

## Development

Run in Chrome browser:

```shell
flutter run -d chrome
```

Analyze sources:

```shell
flutter analyze
```

Format sources:

```shell
dart format lib test
```

Upgrade dependencies:

```shell
dart pub upgrade
```

Check for out of date dependencies:

```shell
dart pub outdated
```

## Build

```shell
flutter build web --base-href "/" --release
```
